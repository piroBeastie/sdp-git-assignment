Step 1 - Local Repository Setup
-------------------------------
git init -b main
    Turned my project folder into a Git repo (makes the hidden .git folder).
    -b main names the first branch main instead of master.

git status
    Tells me the current branch and what is untracked, changed or staged.
    I kept running it between steps to check before committing.


Step 2 - Git Workflow
---------------------
git add index.html about.html
    Put both HTML files in the staging area so the first commit picks
    them up.

git commit -m "Initial commit: add index.html and about.html"
    Saved the starting version of the project as commit no. 1. The text
    after -m is the commit message.

git add about.html
git commit -m "Update about.html with course details and home link"
    After editing about.html I staged it again and made commit no. 2.

git branch feature
    Made a new branch called feature, starting from the commit I was on.

git branch
    Prints the local branches. The one with * is the one I am on.

git checkout feature
    Moved me from main to feature, so my next commit goes on feature.

git add index.html
git commit -m "Add navigation menu to index.html"
    Committed the new nav menu in index.html. At this point only feature
    has this commit, main does not.

git checkout main
    Took me back to main (index.html goes back to the version without
    the menu).

git merge --no-ff feature -m "Merge feature branch into main"
    Brought the feature commit into main. --no-ff forces a merge commit,
    so the branch stays visible in the log graph.

git log --oneline --graph --all
    Short history of every branch, one commit per line, with lines that
    show where feature split off and joined back.

git log
    Long form of the history: full commit id, author, date and message.


Step 3 - .gitignore
-------------------
git add .gitignore
git commit -m "Add .gitignore to ignore log files and temp folder"
    Committed the .gitignore file. Its two rules are *.log (any log file)
    and temp/ (the whole temp folder), so Git skips both.


Step 4 - Undo Operation
-----------------------
git add contact.html
git commit -m "Add contact.html page"
    Extra commit that adds contact.html, made so there is something to undo.

git log --oneline
    One line per commit. I ran it before and after the undo to compare.

git revert HEAD --no-edit
    Undid my last commit by adding a new commit that removes contact.html.
    Old history stays, which matters once the repo is on GitHub. --no-edit
    keeps Git's default message so no editor opens.


Step 5 - GitHub Integration
---------------------------
gh repo create sdp-git-assignment --public --description "SDP assignment - Git and GitHub workflow"
    This one is the GitHub CLI, not git. It made the empty public repo on
    my GitHub account.

git remote add origin git@github.com:piroBeastie/sdp-git-assignment.git
    Linked my local repo to the GitHub repo under the short name origin.

git remote -v
    Shows the fetch and push URL of origin, to confirm the link worked.

git push -u origin main
    Uploaded main with all its commits. -u saves origin/main as upstream,
    so after this a plain "git push" is enough.

git push -u origin feature
    Uploaded the feature branch too, so it also shows on GitHub.

git branch -a
    Lists my local branches plus the remote ones (remotes/origin/...).
